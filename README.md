# Nico Side Comment

ニコニコ動画のフルスクリーン表示中に、コメントリストをサイドバー表示するブラウザ拡張機能（Chrome / Firefox 対応）。

## 機能

- フルスクリーン時に動画右側へコメントサイドバーを表示（**初期状態は非表示**）
- 全コメントをタイムコード順に表示
- 動画再生位置に合わせて自動スクロール + 現在位置のコメントをグレーでハイライト
- 手動スクロールをすると自動スクロールを一時停止（ボタンで復帰）
- ツールバーアイコンクリックで ON/OFF 切り替え
- sm動画・so動画（チャンネル動画）の両方に対応

## 仕組み

- ニコニコの公式コメント API（nvcomment）から全コメントを一括取得
- タイムコード（vposMs）をミリ秒単位で管理し、ソート・再生位置同期を実施
- SPA遷移（動画A→動画B）時にコメントを自動リセット
- 動画プレイヤーのコントローラーに切替ボタンを注入（Reactの再レンダリングに耐える設計）

## インストール

### Chrome

1. `chrome://extensions/` を開く
2. デベロッパーモードを有効化
3. 「パッケージ化されていない拡張機能を読み込む」から本ディレクトリを選択
4. ツールバーアイコンをクリックして有効化（緑色 = ON）

### Firefox

配布されている**署名済み xpi** を使用します。

1. xpi ファイルをダウンロード
2. Firefox で xpi ファイルを開く（またはファイルを Firefox ウィンドウにドラッグ＆ドロップ）
3. インストール確認ダイアログで「追加」をクリック

開発用に zip を読み込む場合は `about:debugging` → 「この Firefox」タブ → 「一時的なアドオンを読み込む」で `nico-side-comment.zip` を選択します（Firefox を再起動すると解除されます）。

## 使い方

1. ニコニコ動画の視聴ページ（`https://www.nicovideo.jp/watch/*`）を開く
2. プレイヤーの全画面ボタンをクリック（F11 ではありません）
3. プレイヤーにカーソルを合わせると表示されるコントローラー内の**サイドバー切替ボタン**をクリック
4. 動画右側にコメントリストが表示される

### サイドバー切替ボタン

コントローラーの「コメントを非表示にする」ボタンの隣にあります。

| 状態 | アイコン | 動作 |
|------|---------|------|
| サイドバー非表示 | 枠 + 横線3本 | クリックで表示 |
| サイドバー表示 | 塗りパネル + 斜線 | クリックで非表示（動画が全画面に復帰） |

## ファイル構成

```
├── manifest.json    # 拡張機能定義 (Manifest V3、Chrome/Firefox互換)
├── background.js    # Service Worker / background script（ON/OFF切り替え）
├── content.js       # メインロジック（コメント取得・サイドバー表示）
├── sidebar.css      # サイドバーoverlay用スタイル
├── icons/           # ツールバーアイコン
└── KNOWLEDGE.md     # ニコニコAPI・DOM解析の知見メモ（ローカル管理）
```

## 配布物

| ファイル | 内容 |
|---------|------|
| `*.xpi` | **署名済み Firefox 用インストールファイル**（配布用） |
| `nico-side-comment.zip` | 開発用（AMO 提出・一時アドオン読み込み用） |

※ zip / xpi は git 管理外（.gitignore 対象）です。

## 技術メモ

- コメント取得: `POST https://public.nvcomment.nicovideo.jp/v1/threads`
- threadKey: `nvapi.nicovideo.jp/v1/comment/keys/thread` で取得（有効期限約3分）
- so動画はスレッドIDが複数あるため、全スレッドを対象に取得
- 詳細は `KNOWLEDGE.md` 参照
